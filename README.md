# Hickman Digital Growth

A responsive one-page website for Hickman Digital Growth.

## Deploy with Vercel
1. Import this GitHub repository into Vercel.
2. Select the root directory and leave the framework preset as Other.
3. No build command or output directory is required for this static HTML site.
4. Deploy.

The contact form opens the visitor's email app with an inquiry addressed to hickmandigitalgroup@gmail.com. It does not store submissions automatically.
